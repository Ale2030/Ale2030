### 🌟 Proyectos Destacados

#### **Gestión de Roles y Usuarios**
- **Tecnologías**: Java, Spring Boot, JPA, Spring Security.
- **Descripción**: Sistema de gestión con funcionalidades avanzadas de autenticación y autorización según roles asignados, además de logs de auditoría para trazabilidad.
- **Características**:
  - APIs RESTful para integración externa.
  - Interfaz web con HTML, CSS y Bootstrap.
  - Seguridad con Spring Security.

#### **Consumo de API de Películas**
- **Tecnologías**: Node.js, Express, HTML, CSS, JavaScript.
- **Descripción**: Aplicación web para consultar información de películas populares a través de una API pública.
- **Características**:
  - Búsqueda por título.
  - Visualización de detalles como sinopsis, calificación y póster.
  - Diseño responsivo para dispositivos móviles.

#### **Biblioteca API REST**
- **Tecnologías**: Java, Spring Boot, HTML, CSS, JavaScript.
- **Descripción**: API REST para gestionar libros, autores y categorías.
- **Características**:
  - Operaciones CRUD completas.
  - Búsqueda avanzada por título, autor o género.
  - Interfaz web responsiva.

#### **Aplicación de Clima**
- **Tecnologías**: HTML, CSS, JavaScript.
- **Descripción**: Consulta en tiempo real del clima a través de una API pública.
- **Características**:
  - Búsqueda por ciudad.
  - Visualización de temperatura, humedad y estado del clima.
  - Diseño atractivo y adaptado a dispositivos móviles.
